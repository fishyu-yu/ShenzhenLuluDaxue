# ShenzhenLuluDaxue · 深圳噜噜大学

一个以水豚噜噜为主题的加载跳转页：中世纪风格的镂空徽章、环绕校名、金色进度环，加载完成后跳转到深圳信息职业技术大学官网。

> 本网页与深圳信息职业技术大学无关，为非商用趣味项目。
> 水豚噜噜形象版权归铁罐（北京）文化传媒有限公司所有。

## 目录

- `site/index.html`：页面（纯静态，无需构建）
- `site/lulu.jpg`：噜噜头像

## 本地预览

在 `site` 目录起任意静态服务器即可，例如：

```bash
npx serve site
```

## 部署

把 `site/` 里的全部文件上传到网站根目录。跳转地址在 `index.html` 脚本里的 `TARGET` 常量中修改。
